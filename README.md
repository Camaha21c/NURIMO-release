# NURIMO 받는 곳

**NURIM + ONE · 일상의 디지털 도구를 하나로.**

Windows 통합 생산성 프로그램입니다. 캡처 · 이미지 · PDF · 미디어 도구를 한 앱에 담았습니다.
**파일을 끌어다 놓으면 그 파일로 할 수 있는 일을 보여줍니다** — 도구를 찾게 하지 않습니다.

> 이 저장소는 **받는 곳**입니다. 소스는 따로 비공개로 둡니다.

## 받기

[**Releases**](../../releases/latest) 에서 받습니다.

| | |
|---|---|
| `NURIMO-<판>-setup.exe` | 설치본. **관리자 권한이 필요 없습니다.** |
| `NURIMO-<판>-portable.zip` | 풀어서 바로 실행. 설정·기록이 **ZIP 옆 `data` 폴더**에만 쌓이고 기기에 아무것도 남기지 않습니다. |

## 처음 실행하면 경고가 뜹니다

**코드 서명을 하지 않았습니다.** 그래서 Windows SmartScreen 이
「Windows의 PC 보호」 창을 띄웁니다. **추가 정보 → 실행**을 눌러야 설치됩니다.

서명은 값과 절차 때문에 아직 하지 않았습니다. 불편하시면 받지 않으셔도 됩니다 —
경고를 무시하라고 권하지 않습니다. 판단은 받는 분 몫입니다.

## 할 수 있는 것

| 갈래 | 도구 |
|---|---|
| 캡처 | **전역 단축키로** — 영역 `Ctrl+Shift+A` · 전체 `Ctrl+Shift+F` · 맨 앞 창 `Ctrl+Shift+W` · **녹화** `Ctrl+Shift+R`(영역) / `Ctrl+Alt+R`(전체, 다시 누르면 멈추고 저장) · **클립보드 그림 가져오기**(`Ctrl+V`) |
| 이미지 | 형식 변환(JPG·PNG·WebP) · 크기 변경 · **용량 맞추기**(5·3·1MB 이하로) · PDF 로 묶기 · 표시 넣기(화살표·네모·글자·모자이크·번호) |
| 읽는 그림 | PNG · JPG · WebP · BMP · GIF · ICO · **TIFF · SVG · TGA**(내장) · HEIC · AVIF · Raw · JPEG XL(**Windows 코덱이 있으면**) |
| PDF | 병합 · 분할 · 페이지 추출/삭제/회전 · 압축 · 그림으로(PNG·JPG) |
| 미디어 | 영상 → MP4 · **영상 → GIF** · 음원 추출(MP3·M4A·WAV·FLAC) |

공통 — 작업 큐 · 진행률 · 취소 · 작업 기록(다시 실행) · 트레이 상주 ·
탐색기 오른쪽 클릭 메뉴(**깔면 바로 들어감 · 창을 띄우지 않고 돌고 알림으로 답함** ·
여러 개를 골라도 한 작업으로, 15개까지) · 끝나면 알림 ·
**흐름 저장·재실행** · **폴더 감시 자동화** · **붙여넣기(`Ctrl+V`)**

### 원본은 건드리지 않습니다

모든 도구가 **읽기만 하고 새 파일로 만듭니다.** 결과는 먼저 임시 이름으로 쓰고
끝까지 성공했을 때만 확정하므로, 도중에 멈춰도 **반쯤 만들어진 파일이 정상 파일인 척하는 일이 없습니다.**
같은 이름이 있으면 덮어쓰지 않고 `이름 (1).ext` 로 비켜 갑니다.

## 영상·음성 기능은 ffmpeg 이 있어야 합니다

NURIMO 는 **ffmpeg 을 함께 배포하지 않습니다** — 널리 쓰이는 Windows 빌드가 GPL 이고
코덱 특허 문제가 따로 있기 때문입니다. 아래를 한 번만 실행하시면 됩니다.

```powershell
winget install Gyan.FFmpeg
```

없어도 나머지 기능은 모두 돌아가고, 영상·음성 도구는 **누르기 전에**
「준비 필요」로 표시됩니다.
