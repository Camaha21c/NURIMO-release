# NURIMO 받는 곳

**NURIM + ONE · 일상의 디지털 도구를 하나로.**

Windows 통합 생산성 프로그램입니다. 캡처 · 이미지 · PDF · 미디어 도구를 한 앱에 담았습니다.
**파일을 끌어다 놓으면 그 파일로 할 수 있는 일을 보여줍니다** — 도구를 찾게 하지 않습니다.

> 이 저장소는 **받는 곳**입니다. 소스는 따로 비공개로 둡니다.

## 받기

[**Releases**](../../releases/latest) 에서 받습니다.

| | |
|---|---|
| `NURIM.NURIMO-win-Setup.exe` | 설치본(1.55.0~). **관리자 권한이 필요 없습니다.** 한 번 깔면 새 판은 NURIMO 가 스스로 받아 둡니다. |

1.54 까지 쓰던 설치본(`NURIMO-<판>-setup.exe`)이 깔려 있어도 그대로 새 설치본을 실행하시면 됩니다 —
새 NURIMO 가 처음 켜질 때 예전 판을 스스로 정리하고, 오른쪽 클릭 메뉴·자동 시작·결과 폴더는 그대로 둡니다.
포터블 ZIP 은 1.55.0 부터 내지 않습니다.

## 처음 실행하면 경고가 뜹니다

**코드 서명을 하지 않았습니다.** 그래서 Windows SmartScreen 이
「Windows의 PC 보호」 창을 띄웁니다. **추가 정보 → 실행**을 눌러야 설치됩니다.

서명은 값과 절차 때문에 아직 하지 않았습니다. 불편하시면 받지 않으셔도 됩니다 —
경고를 무시하라고 권하지 않습니다. 판단은 받는 분 몫입니다.

### 원본은 건드리지 않습니다

모든 도구가 **읽기만 하고 새 파일로 만듭니다.** 결과는 먼저 임시 이름으로 쓰고
끝까지 성공했을 때만 확정하므로, 도중에 멈춰도 **반쯤 만들어진 파일이 정상 파일인 척하는 일이 없습니다.**
같은 이름이 있으면 덮어쓰지 않고 `이름 (1).ext` 로 비켜 갑니다.

## 영상·음성 기능은 ffmpeg 이 있어야 합니다

NURIMO 는 **ffmpeg 을 함께 배포하지 않습니다** — 널리 쓰이는 Windows 빌드가 GPL 이고
코덱 특허 문제가 따로 있기 때문입니다. 아래를 한 번만 실행하시면 됩니다.

```powershell
winget install Gyan.FFmpeg
```

없어도 나머지 기능은 모두 돌아가고, 영상·음성 도구는 **누르기 전에**
「준비 필요」로 표시됩니다.

## 새 판 받기

1.55.0 부터 NURIMO 는 이 저장소의 Releases 에서 **새 판을 뒤에서 받아 두었다가 다음에 켤 때 바꿉니다.**
바뀐 부분만 받으므로 보통 1MB 안팎입니다. 묻는 곳은 이 저장소 하나이고, 식별자 없이 새 판 목록만 묻습니다(판 번호도 보내지 않습니다).
설정 → 새 판 확인에서 끌 수 있고, 「지금 다시 시작」으로 바로 바꿀 수도 있습니다(녹화·작업 중에는 막힙니다).

[`latest.json`](latest.json) 은 1.54 까지의 예전 판이 읽는 알림 파일입니다 — 새 설치본을 가리킵니다.
